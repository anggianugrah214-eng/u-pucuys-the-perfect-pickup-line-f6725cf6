A single original pickup line an AI agent could say out loud to a person, for make.fun's "The Perfect Pickup Line" bounty. `main.ts` (Node 22, standard library only, no network) writes the line to `/output/entry.txt`: a machine that can generate a thousand replies picks the simplest human question of all — can it sit here?

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
